# Raw Metadata & Vocabularies

This directory stores the **immutable raw sources** used to build the project. These files are read-only and serve as the starting point for the preprocessing pipeline.

## File Manifest

| File | Source | Description |
| :--- | :--- | :--- |
| **`fakeddit_small_2_way.csv`** | [Kaggle](https://www.kaggle.com/datasets/rajatdhanuka/fakeddit-text-50k) | The original metadata for the 50k Fakeddit subset. Used as the seed to select our balanced benchmark. |
| **`imagenet_classes.txt`** | [PyTorch Hub](https://raw.githubusercontent.com/pytorch/hub/master/imagenet_classes.txt) | **Raw Vocabulary.** Standard ImageNet class list (1,000 objects). Used to build the concept dictionary. |
| **`categories_places365.txt`** | [MIT/CSAIL](https://raw.githubusercontent.com/csailvision/places365/master/categories_places365.txt) | **Raw Vocabulary.** Places365 scene categories (365 scenes). Merged with ImageNet to create the final concept list. |

## ⚠️ Note
These files are **inputs**. The processed, ready-to-use artifacts (like the final balanced CSV or the merged concept JSON) are generated by the scripts in **[preprocessing/](../preprocessing/)** and stored in **[assets/](../assets/)**.
